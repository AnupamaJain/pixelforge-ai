# Marketing videos

Motion graphics built with [Remotion](https://remotion.dev) — videos authored
as React components, so they inherit the product's real design tokens from
`video/theme.ts` and stay visually identical to the website.

## Output

| File | Format | Duration | Use |
|---|---|---|---|
| `out/pixelforge-hero.mp4` | 1920×1080 | 24s | Landing page, YouTube, demos |
| `out/pixelforge-social-vertical.mp4` | 1080×1920 | 15s | Reels, TikTok, Stories |
| `out/pixelforge-social-square.mp4` | 1080×1080 | 15s | Feed posts, LinkedIn |

## Commands

```bash
npm run video:studio   # live preview + scrubbing
npm run video:hero     # render the 16:9 demo
npm run video:social   # render the 9:16 cut
npm run video:square   # render the 1:1 cut
npm run video:all      # render everything
```

Requires Chrome (Remotion renders through headless Chromium) and ffmpeg, both
of which Remotion bundles or discovers automatically.

## Structure

```
video/
  index.ts                     entry point — registers the root
  Root.tsx                     composition registry (sizes, durations)
  theme.ts                     colours and timing, mirroring app/globals.css
  components/primitives.tsx    FadeUp, PopIn, Badge, Wordmark, GridBackdrop
  compositions/
    HeroDemo.tsx               hook -> problem -> pipeline -> proof -> CTA
    SocialVertical.tsx         cost hook -> proof -> CTA
```

## The hero edit

The 24-second demo spends most of its runtime on the one thing competitors
cannot claim:

1. **Hook** — "Product photography without the photoshoot"
2. **Problem** — every other AI tool redraws your product
3. **Pipeline** — your photo → cut out → scene generated → composited back
4. **Proof** — pixels checked, zero changed
5. **CTA** — 30 free credits

## Assets

`public/showcase/product-cutout.png` is a real alpha cutout, generated by
thresholding luminance on the source photo with a feathered edge. The
backdrops (`scene-studio`, `scene-wood`, `marble`) are generated procedurally
with SVG gradients rather than sourced from stock, so there is no licence to
track and the palette matches the brand.

Regenerate them by re-running the scripts in git history, or replace the files
directly — the compositions only reference paths.

## Before publishing

- **Swap in real output.** The product shot is a stock placeholder. Once you
  have genuine generations, replace `product-cutout.png` and the backdrops so
  the video shows what the product actually produces.
- **No audio track is included.** Add music in your editor, and make sure it is
  licensed for commercial use — this is the most common way a marketing video
  gets a copyright claim.
- **Captions.** Most social video is watched muted. Burn in captions or supply
  an SRT.
